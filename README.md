## Projetos em destaque

### [GastroHub](https://github.com/vineog23-boop/gastrohub)
**Projeto em equipe · Tech Challenge FIAP**

Backend para uma plataforma de restaurantes, com gerenciamento de usuários, endereços e autenticação.

- Autenticação com JWT, perfis de acesso e proteção de senhas com BCrypt.
- Persistência com MySQL e JPA, migrations Flyway e ambiente com Docker Compose.
- Validação de dados, respostas de erro padronizadas e documentação OpenAPI.
- Testes unitários e de integração.

**Java 21 · Spring Boot · Spring Security · MySQL · JUnit · Mockito**

### [Medflow](https://github.com/vineog23-boop/Medflow)
**Projeto pessoal · Em desenvolvimento**

API para gerenciamento de pacientes e ordens de exame. O estágio atual inclui CRUD, consultas paginadas, validações, DTOs e tratamento padronizado de erros.

O projeto organiza o código por funcionalidade e reúne testes de domínio, serviços e camada HTTP. A configuração de infraestrutura e os fluxos de mensageria fazem parte das próximas etapas.

**Java 21 · Spring Boot · Spring Data JPA · Bean Validation**

### [Gestão de Vagas API](https://github.com/vineog23-boop/gestao-vagas)
**Projeto de estudo**

API para cadastro e gerenciamento de candidatos, com persistência via JPA, validação de entrada e tratamento global de exceções.

**Java · Spring Boot · JPA · H2**
